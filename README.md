# 🏷️ Ejercicio 4 — Producto y Cálculo de Precios

---

## 📝 Descripción

El sistema permite representar artículos comercializables con su precio base y calcular los valores finales resultantes de aplicar distintos porcentajes de descuento (promociones, pago al contado) o recargos (costos de financiación, tarjetas).

---

## 🚀 Funcionalidades y Requerimientos

### 📦 Clase `Producto`

* **Atributos:**
  * Nombre (String)
  * Precio base (Double)

* **Métodos:**
  * CalcularPrecioConDescuento(porcentaje): Retorna el precio final aplicando un porcentaje de descuento determinado.
  * CalcularPrecioConRecargo(porcentaje): Retorna el precio final aplicando un porcentaje de recargo o interés.
  * MostrarInformacion(): Imprime en pantalla la información básica del producto (nombre y precio base).
